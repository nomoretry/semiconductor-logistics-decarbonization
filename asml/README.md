# ASML 子项目：扰动下的低碳备件库存与空海运联合规划

本子项目已实际运行整数优化实验。它以ASML的备件服务和空运转海运业务为背景，采用公开路线、公开运输排放代理因子及**明确标记的合成SKU、订单和成本参数**。结果不是ASML的真实运营数据或已实现减排量。

**货损风险按用户要求排除。**生产、晶圆良率、产品制造隐含碳和报废亦未纳入本版物流边界。

## 1. 问题与第一版范围

代表性网络为荷兰供应点到新加坡区域仓，选择空运或海运补货。荷兰—新加坡是实验网络设计，不是已核实的ASML具体备件流。

- 4个合成SKU：electrical_module、pump_kit、sensor_unit、actuator_kit；这些名称是实验类别，不是ASML零件编号。
- 主实验为16周，10份合成已承诺订单簿，种子100–109；订单和扰动在规划时已知。
- 空运提前期1周、海运5周；运输单价、SKU价值／质量、容量与年度资金占用率均为情景假设，见[config.json](config.json)。
- 正常空运／海运航线容量分别为每周100件，共享荷兰供货池每周120件；这些都是实验参数。
- 每周末积压必须为0，期末现货必须至少恢复到与各政策相同的初始现货；初始在途量为0。各策略面对相同订单、初始库存、路线与服务约束。
- 初始库存根据基础提前期和合成需求均值设置，并至少覆盖首期订单。详情及每份实例见[instances.json](../reports/instances.json)。

本版是**已知订单与已公告扰动的有限期规划**，还不是面向未知未来需求的在线控制器。100%周末需求满足来自硬约束，不能解释为一个预测或学习算法达到了100%服务。ASML公开的24小时备件服务指标与这里的周度指标也不可直接比较。

## 2. 成本、碳与决策

优化器决定每周、每条路线、每个SKU的整数发运量。总成本包括：

1. 运输费用：每件质量乘以每公斤运价；
2. 在途资金占用：SKU价值乘年度资金占用率，再按运输提前期分摊；
3. 到货后的现货资金占用与仓储费用。

因此便宜但缓慢的海运也会增加在途资金占用。固定采购成本未单独计入；本版没有采购数量折扣、货损或生产优化。成本单位为**假设美元**，不能用作真实公司预算。

物流碳包括运输和现货仓储；运输使用“件数×每件质量kg÷1,000×距离km×kgCO2e／tonne.km”。航空无RF＋燃料WTT因子为0.66646，平均集装箱船＋WTT为0.01977。航空因子已包含8%距离修正，不能再次放大距离。仓储0.04 kgCO2e／件·周为未验证情景假设。来源、单位、完整原始因子和边界见[data_audit_asml.md](../data_sources/data_audit_asml.md)与[selected_emission_factors.json](../data_sources/selected_emission_factors.json)。

碳预算相对**同一订单簿、同一扰动、同一服务条件**下的纯成本最优物流排放设定。`carbon_minus25`要求总物流排放不超过该参考值的75%；整数订货使实际降幅可能略大于25%。

## 3. 已运行的扰动与政策

| 情景 | 已公告变化 |
| --- | --- |
| 正常 | 使用基础网络；所有政策均包含第9–10周的预设较大订单压力 |
| 海运绕行／延误 | 第5–9周发出的海运增加2周提前期，距离改为21,770公里；其他路线不变 |
| 空运运力受限 | 第7–9周空运每周最多8件，是全SKU合计容量 |

每份实例求解6种政策：混合运输纯成本最优、仅空运、仅海运，以及物流碳分别减少至少10%、25%、50%的成本最优方案。主实验共`3情景×10订单簿×6政策=180`次求解。

下表为10份匹配订单簿的均值；成本与排放列分别以假设美元和kgCO2e表示。降幅／增幅是表中均值之比，未将其当作公司整体减排率。

| 情景 | 纯成本最优成本 | 25%碳预算成本 | 成本增幅 | 纯成本最优排放 | 25%碳预算排放 | 实际物流减排 | 两政策均可行 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 正常 | 22,985.67 | 23,940.38 | 4.15% | 8,222.96 | 6,131.47 | 25.43% | 10/10 |
| 海运绕行／延误 | 23,853.73 | 24,215.25 | 1.52% | 10,293.09 | 7,700.78 | 25.18% | 10/10 |
| 空运运力受限 | 23,259.05 | 24,098.80 | 3.61% | 7,842.41 | 5,858.00 | 25.30% | 10/10 |

25%碳预算在三个情景中均有10/10可行且最优解。更紧的约束不能隐藏失败实例：

- 仅海运在每个周度情景中都仅有**5/10**可行解。
- 50%碳预算在每个周度情景中都仅有**9/10**可行解；种子109不可行。
- 汇总文件中这些政策的成本均值只针对可行子集，不能与全10份实例的纯成本均值直接比较，也不能将不可行解记为零成本。

逐实例可行性、求解状态、最优间隙、成本拆分和空运质量占比在[episodes.json](../reports/episodes.json)／[episodes.csv](../reports/episodes.csv)中，聚合见[summary.json](../reports/summary.json)。整数最优性针对声明的模型和输入，不代表对真实业务或未建模风险全局最优。

## 4. 真实相似需求的月度压力检验

额外使用Monash汽车备件需求，而非半导体需求。保留原来的月度时间尺度：从51个月序列中排除缺失，使用前39个月的需求决定候选资格和需求均值，随后按固定随机规则选取40条序列组成10组4-SKU实例；最后12个月作为已承诺需求进行规划。

在该检验中，提前期和仓储／资金系数按月度时间尺度转换，运输参数仍是半导体业务启发的假设，不能称为ASML实证校准。详见[carpartsREADME.md](../data_sources/carpartsREADME.md)。

- 纯成本与仅空运各10/10可行；仅海运7/10可行。
- 25%碳预算为**9/10可行**。不能将这9组平均成本与纯成本10组平均成本直接相比。
- 仅对共同可行的9组匹配比较：纯成本均值为6,710.81，25%碳预算为6,840.39；物流排放均值分别为510.85和355.92。这仍是选择出的可行子集结果，未计入第10组不可行方案的替代成本。

这部分共40次求解，加上主实验，ASML订单网格部分共220次规划求解，不含通知重放或单独敏感性脚本的额外调用。真实汽车需求为外部鲁棒性材料，不是ASML需求、库存或运价记录。

公开仓库保留本节的聚合结果，但不发布外部需求序列、选中序列ID或逐实例结果。公开`episodes.json/csv`、`instances.json`及`plans.json`仅含合成周度实验；ASML子目录分别有180条求解记录、30份实例和162份可行计划。归档`summary.json`及共享报告仍覆盖原220次ASML实验，范围与公开明细不同。下载原数据后执行下方ASML命令，可在本地重新生成外部压力测试的完整明细。

## 5. LLM文本扰动抽取试验的边界

本项目保存了本次ChatGPT会话内的一次性抽取输出、提示词、合成通知与参考标签。ASML有A01–A06共6条通知：5条信息完整，1条缺少明确时间和改变量，应要求澄清。保存的6条结果均匹配参考结构，包括1次澄清。

这里**没有调用外部LLM API**，没有独立选择和测量模型，也没有训练／测试划分、跨提示词比较、调用成本或延迟评测。这不是可靠性已获验证的通用LLM系统；数值重放可复现，重新生成语言模型输出需要新的LLM会话。

对海运延误、运力限制两种通知，各在相同10份订单簿上比较正确结构化输入、保存的LLM抽取与忽略通知：

| 处理方式 | 海运延误满足全部约束 | 空运限容满足全部约束 |
| --- | ---: | ---: |
| 正确结构化输入 | 10/10 | 10/10 |
| 保存的会话内LLM抽取 | 10/10 | 10/10 |
| 忽略通知仍按旧参数规划 | 0/10 | 4/10 |

保存的LLM结构与参考结构一致，因而数值规划结果相同；它证明本次抽取可以正确接入优化模型，不能证明LLM优于人工正确输入。忽略海运通知的10份实例平均当期需求满足率为75.83%，体现通知处理的必要性；有容量违规的计划不能作为可执行方案计算服务收益。

完整记录见[notice_pilot.json](../reports/notice_pilot.json)。编译器仅接受允许的参数修改，不执行LLM生成代码。后续研究应加入未见文本、单位错误、冲突信息与更丰富的扰动分布。

## 6. 复现

在整个项目根目录运行：

```bash
python -m pip install -r requirements.txt
python scripts/download_source_data.py
python -m unittest discover -s tests -v
python scripts/run_experiments.py --project asml
python scripts/evaluate_notice_pilot.py
```

数值网格重跑会写出`reports/`文件；请先保留发布的参考结果。通知脚本重放已保存抽取，不会重新调用语言模型；默认会检查两个子项目。

可先运行轻量校验：

```bash
python scripts/run_experiments.py --project asml --smoke
```

`--smoke`仅使用一个合成订单簿且不跑汽车需求检验，不能当作完整10种子实验。

## 7. 可以继续研究什么

第一版已把约束、数据来源、求解可行性和文本变更接入跑通。下一步可将已知订单改为有预测误差的需求，比较基础库存规则、需求预测＋滚动MPC与学习辅助目标库存；也可以对空运价格、资金占用率、初始库存和航空RF处理做敏感性分析。它们属于后续实验，当前结果没有证明在线适应、预测收益或真实公司减排。
