This directory provides the ASML subset of the study. Public `episodes.json`/`episodes.csv`, `instances.json`, and `plans.json` contain only `demand_set=synthetic_weekly`: 180 solve records, 30 synthetic instances, and 162 feasible plans. They do not include the external car-parts demand sequences, selected series identifiers, or individual external-test results. No external LLM API inference was run.

`summary.json` and the shared report/run manifest retain aggregate statistics from the original full experiment, including 40 external car-parts monthly stress-test solves, so their scope is broader than the public detailed files. Main source, seeds, units, assumptions, and solver provenance are retained in `../../reports/run_manifest.json`.

The public `plans.json` is an uncompressed, synthetic-only export of the archived compressed results. Experiment reruns continue to emit `plans.json.gz`; they do not automatically update this published JSON copy. To reproduce the full ASML experiment locally, first run `python scripts/download_source_data.py`, then `python scripts/run_experiments.py --project asml` from the study root. This regenerates local detail for the external stress tests as well as the synthetic cases.
