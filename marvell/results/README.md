This directory provides the Marvell subset of the study. Public `episodes.json`/`episodes.csv`, `instances.json`, and `plans.json` contain only `demand_set=synthetic_weekly`: 180 solve records, 30 synthetic instances, and 177 feasible plans. No external LLM API inference was run.

Main source, seeds, units, assumptions, and solver provenance are retained in `../../reports/run_manifest.json`. The shared report and aggregate summaries retain the original full experiment, including the external car-parts stress tests performed in the ASML subproject. External demand sequences, selected identifiers, and individual external-test results are omitted from the public detailed files.

The public `plans.json` is an uncompressed, synthetic-only export of the archived compressed results. Experiment reruns continue to emit `plans.json.gz`; they do not automatically update this published JSON copy. Before tests or full reruns, retrieve the original third-party data with `python scripts/download_source_data.py` from the study root, then run `python scripts/run_experiments.py --project marvell`. Use `--project both` to regenerate the full shared grid including the external stress tests locally.
