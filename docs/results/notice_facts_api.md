## E06分歧

原文说TP9在10月停航三周。模型输出`delay=3 week`，证据为`blanked for three weeks`；当前参考为`facts=[]`。

当前任务抽取货物运输总时长、延误或增减量。停航持续时间不直接确定某票货物延误多久：还取决于原订航次、改订和替代服务。因此现有参考不把三周停航直接标成三周运输延误。维护者已选择不填写人工意见；这里保留助手参考及分歧，不视为人工裁定或盲标。

证据子串检查为100%，但E06仍存在语义分歧，说明“能在原文找到”不等于“数量含义正确”。本版只评来源数量，不验证真实内部路线更新。
