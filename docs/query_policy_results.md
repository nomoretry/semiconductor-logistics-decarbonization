# 查询策略 BC 结果

已完成一轮真实参数训练和检查点评估。学习策略减少在线求解调用，但仍存在决策质量损失。它是查询策略的开发实验，不是 LLM 微调、PPO 结果或正式千题验收。

## 设置

配置见[实验协议](query_policy_protocol.md)和[固定配置](../query_policy/config.json)。共126个合成情境：训练72、验证18、开发评估36；情境与上一轮54个参数不重复，状态分支不跨split。只有1个训练种子17。

精确DP分别生成3,520/906/1,512个教师状态。训练采用有多个最优动作的集合NLL，按情境等权；没有把状态数量当成独立任务数。教师生成分别需要3,520/906/1,512次MILP，这些离线成本不能从研究账目中省略。

## 开发评估

遗憾按每个情境的 `(策略期望成本−精确DP成本)/max(1,精确DP成本)` 计算，再对36个情境取均值。期望成本包括付费查询及最终物流成本，枚举全部可能回答，不依赖一次幸运抽样。

| 方法 | 平均成本遗憾 | 最差遗憾 | 每任务期望MILP次数 | 平均查询次数 |
|---|---:|---:|---:|---:|
| 不查询 | 145.5657% | 299.3401% | 1.000 | 0.000 |
| 公开先验优先规则 | 21.5558% | 141.6753% | 1.000 | 2.250 |
| 未训练网络 | 46.7866% | 152.1793% | 1.000 | 1.917 |
| **BC** | **2.0833%** | **9.0558%** | **1.000** | **1.663** |
| 两步搜索，预算13 | 0.3140% | 3.6868% | 16.146 | 1.535 |
| 迭代DP，预算65 | 0.0064% | 0.2309% | 36.511 | 1.464 |

13/65是每次决策的搜索上限；表内是整条任务的期望调用数。BC需要神经网络前向计算和离线训练，不能把调用数减少直接写成端到端加速倍数。所有方法仍使用同一运输MILP，网络并未学习替代整个物流求解器。

## 训练与误差

实际执行80轮、880次参数更新，按验证损失选择第79轮检查点；所选参数相对初始化的L2变化为20.6314。验证集合NLL从1.1252降至0.5412，最优动作集合命中率从35.48%升至80.39%。验证指标使用情境等权，选模没有读取开发评估集结果。

逐节点使用精确教师分解期望成本损失：

| 错误类型 | 36情境合计额外期望成本 |
|---|---:|
| 本应停止却继续查询 | 26.41785 |
| 过早停止查询 | 14.328875 |
| 应查询，但选错路线 | 12.0948625 |

每个情境都验证了“节点到达概率×所选动作的最优后续成本差”之和等于整个策略的成本差。该分析在评估后进行，没有据此重训或更换本次检查点。下一轮优先检验停止决策与训练状态分布，随后再比较同一起点的策略优化；不能预先宣称PPO一定改善结果。

## 复现与证据

```bash
python -m semiconductor_logistics query-bc --output artifacts/query_bc_new
python -m semiconductor_logistics query-bc --verify --output benchmark_results/query_bc_development
python -m scripts.diagnose_query_policy --verify
```

[证据目录](../benchmark_results/query_bc_development)包含任务、逐状态教师值、初始/训练检查点、每轮日志、逐任务完整概率树、汇总和源码身份。验证命令重算教师、重新训练、加载保存的检查点重执行并复算结果。允许等价最优运输方案，但保存的方案仍须满足物理约束且成本最优。验证不会先覆盖已有证据；新运行拒绝写入非空目录。教师与轨迹以可直接审阅的JSONL文本保存；由本地压缩版本转存时逐字节保持解压内容，转换后再次完整验证。

新测试覆盖解析梯度有限差分、候选排列等变、私有字段拒绝、独立预算mask一致性、分组权重、真实训练更新、全世界枚举成本、数值边界、篡改检查点后重算文件哈希仍被拒绝。

## 范围

全部参数来自固定合成生成器，订单已知、先验准确、最多三次查询。36个评估情境已用于开发观察，后续不能再称为未经查看的正式测试集。此前预算实验的失败门槛保持原结论；本轮研究的是独立的在线计算替代问题。PPO、5训练种子、正式约1000题和未知需求滚动决策尚未完成。
