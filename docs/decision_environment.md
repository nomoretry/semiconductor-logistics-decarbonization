# 信息成本与物流决策环境

该开发环境保留已知承诺订单，加入对已公告海运延误的部分信息。订单在第3周到期；空运第1周到达，海运第2周或第4周到达。隐含状态是当前延误的具体情况，不是未知未来需求。

## 工具与状态

策略只接收公开JSON观察：订单、路线、物理系数、延误先验、查询可靠性、目标、费用、预算、已有响应和候选计划。任务编号、随机种子和实际延误不进入观察；动作掩码只依赖公开历史。

| 动作 | 作用 |
|---|---|
| `query_status` | 付费获取有噪声的状态信号，按公开似然更新后验 |
| `request_clarification` | 付费获取模拟中的准确延误信息，不发送真实消息 |
| `solve_nominal` | 在无额外延误下优化目标 |
| `solve_robust` | 最小化两种延误状态中的最坏损失 |
| `solve_bayes` | 最小化当前后验下的期望损失 |
| `commit_plan` | 提交已购买求解结果的整数空海运发货量 |
| `handoff` | 结束并承担未完成订单损失 |

工具受查询次数、求解次数、动作数和金额预算限制。求解费用是公开的模拟使用费，不是实测CPU费用。候选编号只与公开调用顺序有关。

## 物理后果与目标

整数空海运量之和必须等于已知订单。终局根据实际提前期重建到货、库存、积压、运费、持有成本和排放，不接受求解器自报目标值作为可行性证明。模拟损失为：

`运费 + 持有成本 + 积压件周×逾期罚金 + 排放×碳价 + 超碳预算罚金 + 已付工具费`。

奖励为负损失。运输成功另按守恒、全部交付、准时比例及碳预算判断。部分碳与服务目标在严重延误下不可同时满足，报告同时给出物理可行性上限，避免把不可行目标归因于策略。

每个物理情境有成本、服务和碳三个目标版本。它们共享订单、路线、先验、费用、预算及实际状态，只改变公开目标系数。所有数量、概率和费用均为明确的合成设计参数。

## 强基线

固定工作流包括最低运费、风险稳健、始终澄清、先查询再求解，并在费用不足时使用公开回退。适应性基线按一次查询的信息价值决定是否继续；精确Bayes动态规划枚举剩余预算、查询响应及可用候选。

动态规划是这个小模型上可执行的公开信息参考。它的期望损失与两种延误、两种信号的完整加权执行核对。免费获知真实状态、免费选取任意发货量的先知下界另行报告，不作为可执行策略。

## 开发结果

200个物理情境各含3个目标，共600组任务；6种方法共3,600次运行。统计单位是物理情境，目标版本不能当作独立样本。

| 方法 | 平均期望总损失（假设美元） |
|---|---:|
| 最佳单一固定工作流：先查询再求解 | 195.650 |
| 一步信息价值适应性规则 | 173.694 |
| 公开Bayes动态规划 | 173.663 |
| 免费信息与求解的先知下界 | 126.560 |

查询价格变化使44.7%的任务改变最优首个动作，预算放宽使34.3%的任务降低期望损失；34.5%的物理情境因目标变化而改变最优发货量。Bayes策略在27.3%的任务先查询，其余直接求解。物理、目标、查询、求解及预算后果检查均通过。

一步信息价值规则按任务归一后的平均期望遗憾仅0.0295%，低于预先设置的1%开发诊断阈值。精确动态规划不参与这个学习空间阈值的判断。当前没有足够的学习改进空间，BC/PPO保持未训练；下一步应研究多SKU、多路线共享容量和查询预算耦合。

物理服务与碳约束可同时满足的比例上限，在采样世界为88.5%，在模型期望下为87.305%。它们是独立物理可行性界限，不是成本最优策略的成功率。

## 复现

```bash
semiconductor-logistics decision-audit --tasks 200 --output artifacts/decision_audit
semiconductor-logistics decision-audit --verify --output artifacts/decision_audit
```

[开发记录](../benchmark_results/decision_development/)保存任务、实际评估状态、结果、轨迹、反事实检查、源码和文件哈希。验证器重算与重放确定性文件。运行耗时另存`runtime.json`，不参与逐字节重放或业务损失。该集合不是最终约1,000题留出测试，没有训练或API调用。
